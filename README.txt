CRISTIAN CRISTINA — PORTFOLIO WEBSITE

HOW TO OPEN
1. Extract the ZIP file.
2. Open the 'cristian_portfolio' folder.
3. Double-click index.html, or open the folder in Visual Studio Code.
4. In VS Code, use the Live Server extension if you have it installed.

CUSTOMISE
- Replace the sample project descriptions in index.html with your actual project details.
- Add project screenshots to the folder and link them in index.html.
- Add a real profile photo to the CV placeholder in the Word document.
- Check your contact details before publishing the site online.

This is a static website built with HTML, CSS and JavaScript. No installation is required.
